# Credit Risk Analysis

## Project Overview

This project analyzes customer credit and financial data to identify risk patterns, customer behavior, and factors affecting loan approvals. The analysis includes data cleaning, exploratory data analysis (EDA), feature exploration, and data visualization to generate actionable business insights.

### Tools Used

* Python
* Pandas
* NumPy
* Matplotlib

### Key Highlights

* Analyzed 51,336 customer records
* Worked with 88+ financial and demographic features
* Performed data cleaning and preprocessing
* Created 10+ visualizations to uncover credit risk trends
* Generated insights to support data-driven lending decisions
